## 2. Что именно изменено

### Editor-pass с учётом степени сокращения

**До:** Общая команда "сократи до X символов"

**После:** Три уровня сокращения:
- **Light (≤10%):** Очень мягкая редакция — убрать 1-2 слова, сократить одно предложение
- **Medium (10-25%):** Удалить второстепенные детали и повторы
- **Heavy (>25%):** Глубокое сокращение — убрать всё лишнее, оставить только суть

### Безопасный fallback

**До:** Простая обрезка по последнему предложению, могла оставлять "3." и незаконченные фразы

**После:**
- Проверка на обрезку слова посередине
- Удаление оборванных конструкций ("3.", "...")
- Поиск конца предыдущего слова при необходимости
- Многоточие только если текст не заканчивается на знак препинания

### Защита от увеличения текста editor-ом

**До:** Нет проверки

**После:** Если editor вернул текст длиннее исходного — откат к предыдущей версии и прерывание цикла

### Максимум 2 editor-pass

**До:** 1 editor-pass + fallback

**После:** Цикл из максимум 2 editor-pass, затем fallback

### Улучшенные целевые диапазоны

**MEDIUM:** 550–620 символов (было 450–650)
**LONG:** 720–800 символов (было 650–850)

Цель — создать запас на естественную вариативность и снизить частоту превышений.

## 3. Как теперь работает pipeline

```
GENERATE
    ↓
VALIDATE
    ├── OK → SEND (Natural pass)
    │
    └── TOO LONG
           ↓
       EDITOR #1
           ├── Increased text → REVERT → SEND (with original)
           ├── Valid → SEND (Editor pass)
           └── Still too long
                  ↓
              EDITOR #2
                  ├── Increased text → REVERT → SEND (with original)
                  ├── Valid → SEND (Editor pass)
                  └── Still too long
                         ↓
                     SAFE FALLBACK
                         ↓
                         SEND (Fallback pass)
```

**Ключевые изменения:**
- Максимум 2 editor-pass вместо 1
- Защита от увеличения текста editor-ом
- Editor получает точные метрики (current_length, hard_max, over_limit_by)
- Три уровня сокращения в зависимости от превышения

### Editor pass (сокращён editor-ом)

**MEDIUM | Expert | Как ухаживать за бровями дома**
```
Initial: 815 | Final: 672 | Target: 700 | API calls: 3
Over limit by: 115 | Editor reduction: 143 | Editor passes: 2

Многие ошибочно считают, что дома с бровями ничего делать не нужно, достаточно мастера. Это не так. Особенно при отращивании или при густых, жёстких бровях.

Домашний уход начинается с очищения. Обычного умывания недостаточно. Нужно специальное средство для удаления макияжа и пыли, иначе поры забьются, ухудшится рост волосков.

Следующий шаг — увлажнение. Бровям оно тоже необходимо! Специальные масла или сыворотки питают волоски, делая их мягче, послушнее, а также стимулируют рост.

Ежедневное расчесывание щёткой утром и вечером придает форму и улучшает кровообращение, пробуждая спящие луковички.

Если есть вопросы или нужна помощь с выбором средств, напишите мне.
```

**LONG | Expert | Полный гайд по уходу за бровями дома**
```
Initial: 1133 | Final: 709 | Target: 900 | API calls: 2
Over limit by: 233 | Editor reduction: 424 | Editor passes: 1

Многих волнует, как правильно ухаживать за бровями дома. Это несложно, если знать основные правила.

Главное — не экспериментируйте с пинцетом сами, если не уверены в форме. Лучше доверьтесь мастеру, а дома лишь поддерживайте результат.

Ежедневно расчесывайте брови специальной щеточкой. Это улучшает кровообращение, стимулируя рост волосков и делая их аккуратнее.

Питайте брови, как и волосы, маслами: касторовым, репейным или миндальным. Наносите на ночь, смывайте утром.

Не забывайте про очищение. При снятии макияжа аккуратно удаляйте косметику с бровей, чтобы предотвратить забивание пор и выпадение волосков.

Если есть вопросы или нужна индивидуальная консультация по уходу за бровями, напишите мне.
```

## 10. Критерии завершения этапа

### Технически ✓
- Hard max соблюдается (все валидные посты ≤ hard_max)
- Editor-pass вызывается только при необходимости (10/30)
- Editor не увеличивает текст (защита реализована)

- Нет бесконечных циклов (максимум 2 editor-pass)

- Medium остаётся полноценным (средняя 559)
- Long остаётся развёрнутым (средняя 794)
- После сокращения текст остаётся естественным (ручная проверка)
- Смысл не теряется (ручная проверка)

### По статистике ✓
- **Fallback = 0** (главный критерий выполнен)
- Editor-pass снижен с 47-50% до 33%
